# 🏰 2D 타워디펜스 프로젝트

**유니티(Unity)** 기반으로 개발한 2D 타워디펜스 게임입니다.  
플레이어는 다양한 타입의 타워를 배치해 몰려오는 적들의 침입을 막고, 웨이브를 거치며 능력을 강화해 최종 보스를 처치하는 것이 목표입니다.

## 🧩 주요 기능

### ✅ 기본 시스템
- **타워 배치 및 업그레이드**  
  타일맵 위에 다양한 특성을 가진 타워를 배치하고, 강화하여 더 강력한 공격이 가능

- **몬스터 웨이브 시스템**  
  웨이브마다 점점 강해지는 적 등장, 보스 웨이브 존재

- **적 AI 경로 탐색**  
  DFS 및 A* 알고리즘을 활용한 타일 기반 경로 탐색 시스템

- **능력 선택 시스템**  
  웨이브 종료 후 3개의 특성 중 하나를 선택하여 능력 강화 (레어도: Common, Rare, Epic)

### ⚙️ UI 및 기타
- **스테이지 선택 UI**  
  The Binding of Isaac 스타일의 이벤트/보스 스테이지 분기 선택

- **일시정지 및 설정 메뉴**  
  Time.timeScale 조절 및 UI Stack 기반의 정지 시스템

- **오브젝트 풀링 시스템**  
  파티클, 데미지 텍스트, UI 요소에 대해 풀링을 적용하여 성능 최적화
